# XXD Panel 090 オリジナルプロンプト · 日本語読解訳

アップロードした写真を1枚ずつ、それぞれ独立した上質なデザインポスターにしてください。複数画像を組み合わせず、各写真を個別に出力します。全体は3:4の縦構図とし、上下2つの領域の高さを厳密に1:1、それぞれ画面の50%にしてください。

上半分には元の写真を残し、被写体の同一性、構造、姿勢、リアルな質感、自然な光と影、元来の色彩の雰囲気を維持します。アート雑誌、インディペンデント出版物、展覧会用イメージのような質感を持たせるため、わずかに洗練されたカラーグレーディングを施すだけにしてください。画面比率に合わせて周囲の背景を自然に拡張することはできますが、被写体を引き伸ばしたり、歪めたり、改変したりしてはいけません。

下半分では、写真の中で最も識別性の高い**主体、輪郭、姿勢、物語上の関係**を抽出します。ただし元の対象を直接描写せず、その情報を **Diagrammatic Abstraction / Conceptual Mapping** 形式の図式的抽象へと翻訳してください。写真の中心的な対象を「概念中心」と捉え、その動作、方向、空間、感情、関係、比喩を、文字、ノード、軌跡、領域、矢印、接続関係へ分解し、写真の背後にある思考過程と意味構造をそのまま描き出すように表現します。

構図は、**文字意味システム + 幾何学的関係システム + 手作業の痕跡システム**によって一体的に組み立てます。主体の最も重要な輪郭、方向、姿勢を、下層の幾何学的骨格としてほのかに残し、その上に三角形の構造、折れ線、交差軸、放射線、関係線、角度のネットワーク、部分的な囲みを用いて理性的な秩序を形成します。周辺には少量の等高線状の曲線、場の線、波形の軌跡、経路を加え、拡散、流動、収束、伸長といった空間的関係を生み出してください。標準的なフローチャートや科学図表にはせず、絵画、図表、思考ノートの間にある芸術性を保ちます。

画面には、**反復する方向性の短線、リズミカルな筆致、点、目盛り、記号、部分的な手書きの痕跡**を数多く加えることができます。主体の力、速度、感情、空間密度に応じて方向や疎密を変え、mark-making field を形成してください。幾何学的な線は明瞭で鋭く抑制的に保ち、手作業の痕跡にはわずかなずれ、断裂、不均一さを許すことで、理性的な構造と身体性のある筆致の間に緊張を生み出します。関係、方向、情報の間に十分な呼吸が生まれるよう、広い余白を残してください。

配色は上の写真から、**最も生命力があり、最も意味のある1–3色を抽出して再調整**します。写真の色をそのまま写したり、均等に抽出したりしてはいけません。主要な文字と幾何学的骨格には黒、チャコールグレー、または深い混合色を使い、元画像に由来する鮮やかな色でノード、軌跡、密度場、部分的な強調を担わせます。色は明るく、澄んでいて、エネルギーを感じさせながらも過度に飽和させず、広い淡色の地と少量の高強度色によって明確な階層を作ります。濁ったグレー、複雑な混合色、蛍光感、意味のない多色の積み重ねは避けてください。

文字そのものを図形構造として扱い、固定のタイトル、番号、場所、言語はあらかじめ設定しません。写真の主体、動作、関係、感情、音、時間感覚、象徴的意味に応じて、キーワード、短句、概念の断片、独自の記号を自由に抽出し、**大小のコントラスト、回転、反復、重なり、経路に沿った配置、部分的な分解、空間的な接続**を通して構図に参加させます。書体には、**細身で理性的、かすかに実験的な組版の緊張を帯びたエディトリアル書体を使い、字形は明瞭に保ちながら、わずかな伸長、圧縮、傾斜、ベースラインのずれを許容**してください。文字が読めると同時に、図式内のノード、座標、視覚記譜としても機能するようにします。

全体として、**Visual Thinking × Concept Mapping × Diagrammatic Drawing × Experimental Typography × Visual Notation** という実験的な視覚言語を提示します。遠くから見ると明確な幾何学的秩序と視覚的重心があり、近くで見ると文字、軌跡、記号、手作業の痕跡の関係が豊かに広がります。元画像が人物、動物、建築、植物、器物、乗り物、自然景観のいずれであっても、物体の説明図にはせず、**関係、過程、状態、意味**についての視覚思考マップとして捉え直してください。

従来型のマインドマップ、標準的なフローチャート、データダッシュボード、テクノロジー UI、サイバーインターフェース、画面を埋め尽くす規則的なグリッド、装飾的な乱線、複雑な情報の過剰な詰め込み、写実的なイラスト、テンプレート化されたインフォグラフィックは避けてください。
